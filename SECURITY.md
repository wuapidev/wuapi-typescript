# Security

## Reporting a vulnerability

Please report vulnerabilities privately, with GitHub's
[private vulnerability reporting](https://github.com/wuapidev/wuapi-typescript/security/advisories/new)
for this repository. Don't open a public issue.

Include what you found, how to reproduce it and the SDK version. We'll
acknowledge the report, keep you posted while we fix it, and credit you in the
release notes unless you'd rather stay anonymous.

This covers the SDK in this repository. For the wuapi API itself, use the same
form; we route it to the right place.

## Supported versions

Fixes ship in a new release of the latest minor version. We're pre-1.0, so
upgrade to the newest `0.x` to get them.
